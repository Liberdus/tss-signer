#84
Summary
Hardens Liberdus Bridge TSS Server (tss-signer) against DevSecOps / CodeQL findings: abuse of public observer HTTP endpoints, unsafe logging of secrets and user-controlled values, overly permissive CORS, and GitHub Actions workflows without least-privilege GITHUB_TOKEN scopes. Also adds SECURITY.md for coordinated vulnerability reporting.

This repo is TypeScript/Node (observer, TSS tooling) plus Go under tss/; there is no application Rust. CodeQL is scoped so analysis focuses on maintained code, not vendored caches.

Background
The observer exposes HTTP APIs used by:

Bridge UI (often via liberdus-proxy at /observer/*, but optionally direct to observers when notifyObserverDirectly is enabled)
Party-to-party gossip (POST /bridgein/evm/submitted, POST /bridgein/liberdus/submitted) — crypto-verified but still CPU/DB heavy
Admin API (/admin/*) — mounted before CORS; authenticated by source IP against configured observer URLs, not browser origin
CodeQL flagged patterns that increase risk if endpoints are exposed on the public internet: missing rate limits, origin: true CORS, format strings built from request/config data, and RPC URLs or CLI passwords in logs.

Changes (by area)
Observer HTTP hardening (observer/)
Rate limiting — express-rate-limit on app.use("/bridgein", …) so both gossip routes share one limiter (same behavior as per-route limits; clearer for CodeQL).
Default: 120 requests / minute / IP
Override: OBSERVER_BRIDGEIN_RATE_LIMIT_PER_MIN
Response: 429 + { "Err": "Too many requests" }
CORS — new observer/cors.ts:
Replaces cors({ origin: true }) (reflects any origin → CSRF-style risk for credentialed browser calls)
Allows: local dev (http://localhost:*, http://127.0.0.1:*), https://dev.liberdus.com, https://liberdus.com
Extra origins: OBSERVER_CORS_ORIGINS (comma-separated; * suffix = prefix match)
No Origin header → no CORS headers (proxy/curl/gossip unchanged)
/admin still mounted before CORS
Safe logging — chainId and similar values logged with %s and passed as separate arguments where CodeQL flagged tainted format strings
Shared logging (shared/lib/redactForLog.ts)
redactRpcUrlForLog — masks query params (apikey, token, …), userinfo, and Infura-style /v3/{key} path segments
redactCommandArgsForLog — masks --channel_password / --password style flags in regroup CLI logs
Used from httpProviderHelper.ts, rpcUrls.ts, tss-tools/regroup.ts
CI / CodeQL (.github/)
codeql-config.yml — paths-ignore: **/*.rs, tss/.tooling/**
codeql.yml — matrix includes actions, javascript-typescript, go (autobuild); explicit job permissions already present
commitlint.yml — permissions: contents: read, pull-requests: read
test.yml — permissions: contents: read

SECURITY.md — supported versions (1.0.8 / 1.0.x), how to report (public issue vs Security tab), out-of-scope notes
